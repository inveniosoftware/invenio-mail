# Invenio-Mail

[![License](https://img.shields.io/github/license/inveniosoftware/invenio-mail.svg)](https://github.com/inveniosoftware/invenio-mail/blob/master/LICENSE)
[![CI](https://github.com/inveniosoftware/invenio-mail/workflows/CI/badge.svg)](https://github.com/inveniosoftware/invenio-mail/actions?query=workflow%3ACI)
[![Coverage](https://img.shields.io/coveralls/inveniosoftware/invenio-mail.svg)](https://coveralls.io/r/inveniosoftware/invenio-mail)
[![Release](https://img.shields.io/pypi/v/invenio-mail.svg)](https://pypi.org/pypi/invenio-mail)

Invenio-Mail is an integration layer between Invenio and Flask-Mail.

- Free software: MIT license
- Documentation: https://inveniosoftware.github.io/invenio-mail/

## Installation

Invenio-Mail is on PyPI so all you need is:

```console
$ pip install invenio-mail
```
